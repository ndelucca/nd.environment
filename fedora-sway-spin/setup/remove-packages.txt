# Apps que NO queremos en el sistema (vengan del Spin o arrastradas como dependencia
# débil). Las borra 07-remove-unwanted.sh de forma idempotente: solo quita las que
# están instaladas, no falla si ya no están. Una por línea; '#' y vacías se ignoran.
#
# gnome-text-editor: editor de texto nativo de GNOME. No lo usamos (nuestro editor de
# text/plain ya es nvim) y nada lo requiere.
gnome-text-editor

# eog: visor de imágenes viejo (GTK3) de GNOME. Lo reemplazamos por Loupe (GTK4),
# que es el handler de imágenes en 03-apps.sh. Nada lo requiere.
eog

# direnv: estuvo en packages.txt pero nunca se hookeó en bashrc.d (eval "$(direnv hook
# bash)"), así que no hacía nada. Sacado del set; se desinstala para no dejar peso muerto.
direnv

# dunst: daemon de notificaciones de dunst. Nuestro daemon es SwayNotificationCenter
# (lo arranca systemd --user), pero dunst quedaba instalado y registrando el mismo nombre
# de D-Bus: el journal repetía en cada arranque
#   Ignoring duplicate name 'org.freedesktop.Notifications' ... org.knopwob.dunst.service
# swaync ganaba la carrera por lanzarse explícito, pero era una condición latente.
# Nada lo requiere.
dunst

# abrt: reporte automático de crashes de Fedora. Deja 4 daemons corriendo (abrtd,
# abrt-oops, abrt-journal-core y abrt-xorg — este último vigila un log de Xorg que en una
# sesión Wayland pura no existe). No lo usamos y en una máquina de 4 GB no se justifica.
# Basta con quitar 'abrt': dnf arrastra los addons, la GUI y libreport como dependencias.
abrt

# low-memory-monitor: avisador de presión de memoria de GNOME, sin usar acá (nada lo
# requiere y no hay GNOME Shell). Su función la cubre systemd-oomd, que sí habilitamos
# en 11-memory.sh.
low-memory-monitor

# --- Agentes de invitado de VM ---
# Esta máquina es bare metal (`systemd-detect-virt` dice "none"): es un Acer Aspire 5742.
# El live image del Spin trae igual los agentes de invitado de los tres hipervisores, con
# sus units habilitadas (vboxservice.service, vmtoolsd.service) y sus autostarts colgando
# de graphical-session.target (app-vboxclient@, app-vmware-user@). Se auto-detectan y
# quedan inactive, así que no cuestan RAM — pero son paquetes y units que nadie declaró.
# Si alguna vez este setup corre DENTRO de una VM, sacarlos de esta lista y reinstalarlos.
virtualbox-guest-additions
open-vm-tools
spice-vdagent

# --- Stack del instalador (Anaconda) ---
# Anaconda es el instalador de Fedora: sirve mientras corrés el live ISO y no hace nada
# en un sistema ya instalado. Quedó de la instalación original junto con dracut-live (el
# módulo de dracut que arma el initramfs del live) y el autostart app-liveinst-setup@.
# Listar anaconda-core arrastra como dependientes a anaconda-live/-tui/-webui y a
# kdump-anaconda-addon. libreport-anaconda va aparte porque es DEPENDENCIA de
# anaconda-core, no dependiente: sin nombrarlo quedaría huérfano.
# Nota: se lleva puesto también `slitherer` (el jueguito de la víbora del Spin), que
# depende de anaconda-webui. Es esperado, no un daño colateral sorpresa.
anaconda-core
libreport-anaconda
dracut-live

cockpit-ws

cockpit-bridge
